# Скріншоти (опційно)

Це місце під скріншоти реального прогону на Whitechain testnet, коли він
буде зроблений (див. `DEPLOY_WHITECHAIN.md`). Поки Фаза 1 перевірена лише
локально (мережевий доступ до whitechain.io заблокований у цьому
середовищі розробки — див. README, розділ "Step 0"), тут порожньо.

Коли прогониш `python scripts/demo.py` проти реального testnet:
- `terminal.png` — вивід у терміналі (усі шість рядків `[OK]`)
- `explorer.png` — сторінка адреси гаманця facilitator-а в Whitechain
  explorer (`https://testnet.whitechain.io/address/...`) з видимими
  транзакціями tEURC

і додай теги `![...](docs/screenshots/terminal.png)` /
`![...](docs/screenshots/explorer.png)` назад у README.md.
