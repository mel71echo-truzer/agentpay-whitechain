# AgentPay x402 — Крок 2–4: facilitator, платний ендпоінт, агент-покупець

Це «серце» проєкту: повний цикл x402-оплати між AI-агентами на Whitechain.
Все на Python — жодного Solidity.

## Що тут відбувається (простими словами)
1. **Агент-покупець** хоче купити преміум-фото і стукає на сервер.
2. **Сервер-продавець** відповідає «402 Payment Required»: ось скільки, ось кому і яким токеном плати.
3. Агент **підписує** дозвіл на переказ (EIP-3009) своїм ключем — без газу, off-chain.
4. **Facilitator** бере цей підпис і виконує переказ **on-chain**, платячи газ (WBT).
5. Сервер бачить, що оплата пройшла, і віддає фото + посилання на транзакцію в explorer.

```
buyer_agent  ──(1) GET /premium──▶  resource_server
             ◀──(2) 402 + умови───
             ──(3) підпис EIP-3009─▶
                                   ──(4) /settle──▶ facilitator ──▶ Whitechain
             ◀──(5) фото + txHash──
```

## Файли
| Файл | Що це |
|---|---|
| `common.py` | побудова та підпис EIP-3009 (спільне) |
| `facilitator.py` | сервіс: `/verify` (off-chain) і `/settle` (on-chain переказ) |
| `resource_server.py` | «продавець»: 402 + віддача контенту після оплати |
| `buyer_agent.py` | AI-агент: підписує оплату й купує (опційно рішення через Claude) |
| `run_demo.py` | запускає всю демку однією командою |

## Перевірено (мною, без твоєї участі)
- контракт компілюється, EIP-3009 typehash-і збігаються з еталоном Circle;
- повний цикл підпису: `sign → recover` дає ту саму адресу, яку перевіряє контракт;
- підроблена сума відхиляється; кодування заголовка X-PAYMENT працює.

Лишилось прогнати це проти **реального** testnet — а це вже потребує твого гаманця з газом.

## Як запустити демо на Whitechain testnet (твоя частина, ~5 хв)

### 1. Встанови Python-залежності
У теці `agentpay` (там же, де `.env`):
```
pip install -r x402/requirements.txt
```

### 2. Додай у .env адресу отримувача оплати
Відкрий `.env` (`notepad .env`) і додай рядок з адресою **будь-якого іншого** свого акаунта
(наприклад Account 1 з MetaMask) — саме він отримуватиме apUSD:
```
PAY_TO_ADDRESS=0x...(інша твоя адреса, НЕ AgentPay Test)
```
Решта вже є: `PRIVATE_KEY` (агент і facilitator використають його), `TOKEN_ADDRESS`, `RPC_URL`.
Для демо покупець і facilitator — один акаунт AgentPay Test (у нього є і apUSD, і WBT на газ). Це нормально для першої версії; у продакшені facilitator — окремий оператор.

### 3. Запусти демо однією командою
```
python -m x402.run_demo
```
Очікуваний результат:
```
✓ обидва сервіси готові
Агент-покупець: 0x76E6...1d86
Потрібна оплата: 10000 одиниць -> 0x...(PAY_TO)
✅ Куплено! Транзакція: https://testnet.whitechain.io/tx/0x...
Контент: 🖼️  Ось твоє преміум-фото: ...
```
Відкрий посилання на транзакцію — це і є доказ автономної агентної оплати на Whitechain.

### (Опційно) щоб рішення про оплату приймав Claude
Додай у `.env`: `ANTHROPIC_API_KEY=sk-ant-...` — тоді агент спитає Claude «купувати чи ні» в межах бюджету.
